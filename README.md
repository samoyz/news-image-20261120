One image summing up the world's news of Friday 20 November 2026.

`main.ts` (Node 22, stdlib only) renders a 1024x1536 newspaper-style poster
to `/output/entry.png` with a pure-JS PNG encoder (raw RGBA buffer +
node:zlib deflate + PNG chunks with CRC32) and a 5x7 bitmap font. No network,
no dependencies, deterministic output.
